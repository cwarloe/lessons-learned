TITLE
Don't Repeat Yesterday's Mistakes
A living catalog of lessons, patterns, and reusable resources to review before starting new work.
ACT 1: SETUP
Setting Role
You're about to start a new project, much like the games and apps you've already built. You're the developer who will hit the same bugs and pitfalls unless something changes.
Point A (Where am I?) Call to Action (How do I get from A to B?) Point B (Where do I want to be?)
Hard-won fixes live in memory and scattered code, so mistakes repeat and projects start from scratch. Scan the lessons, pull reusable code, and record new lessons afterward. A stronger starting point: fewer repeated bugs and faster setup.
TRANSITION 1
This repo captures what past projects taught. Three ideas help you use it: what it catalogs, how lessons stay in context, and what you can reuse.
